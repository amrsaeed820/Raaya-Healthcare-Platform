This is the dedicated administration and management dashboard for the nursing staff of the **Raaya Healthcare Platform**. It is an independent React application designed to streamline the workflow of medical professionals.

## ✨ Features
- **Centralized Dashboard**: A unified overview of daily tasks, upcoming appointments, and financial earnings.
- **Request Management**: Nurses can seamlessly accept, decline, or view details of incoming patient requests.
- **Availability Control**: One-click toggles to switch between "Online/Available" and "Offline" statuses.
- **Profile & Verifications**: Upload credentials, manage specialties, and track verification statuses securely.
- **Secure Access**: Protected routes and restricted access strictly limited to verified medical professionals.

## 🛠️ Available Scripts

In the project directory, you can run:

### `npm install`
Installs all frontend dependencies needed for the Nurse Dashboard.

### `npm run dev`
Runs the dashboard in development mode.
Open [http://localhost:5174](http://localhost:5174) (or the port Vite assigns) to view it in the browser.

### `npm run build`
Builds the app for production to the `dist` folder.
This optimizes the React components, removes development comments, and compresses the assets for maximum deployment speed.

### `npm run preview`
Locally preview the production build to test performance before shipping to servers.
